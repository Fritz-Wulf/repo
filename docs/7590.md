# FRITZ!Box 7590

Status: **INFERRED** for Fritz.Wulf. Freetz-NG evidence identifies the non-AX 7590 as HWR 226 with a GRX5 MIPS platform operating big-endian.

The kernel is firmware-dependent within the 4.9 series; the Freetz-NG 08.20 configuration uses Linux 4.9.337. Freetz-NG lists FRITZ!OS through 08.25, but Fritz.Wulf does not assign a kernel version to 08.25 without firmware-specific extraction.

Freetz uses a separate uClibc-ng runtime under `/usr/lib/freetz`; AVM's libc can vary on newer FRITZ!OS. The provisional Fritz.Wulf package architecture is `mips32-grx5-be`.

Freetz-NG documents incorrect/stale AVM kernel configurations for some 7590 source bundles and constraints around replace-kernel support. Package/runtime compatibility must therefore remain separate from firmware-flash support. Do not substitute 7590 AX artifacts.
