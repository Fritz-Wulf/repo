# FRITZ!Box 7530

Status: **INFERRED** for Fritz.Wulf. Freetz-NG and OpenWrt evidence identify the non-AX 7530 as HWR 236, Qualcomm IPQ40xx/IPQ4019, 32-bit ARMv7 and little-endian.

Freetz kernel configurations use Linux 4.4.271 across several modern firmware generations. Freetz-NG lists FRITZ!OS through 08.25, but Fritz.Wulf does not assign a kernel version to 08.25 without firmware-specific extraction.

Freetz uses a separate uClibc-ng runtime under `/usr/lib/freetz`; AVM's libc can vary on newer FRITZ!OS. The provisional Fritz.Wulf package architecture is `armv7-ipq40xx`. Do not use 7530 AX packages or images for this profile.

No Fritz.Wulf hardware flash validation is claimed by this profile.
