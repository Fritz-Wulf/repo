# FRITZ!Box 7490

The Fritz.Wulf 7490 profile is `HISTORICAL VERIFIED` for the documented FRITZ!OS 07.62 / Freetz-NG reference only. It must not be generalized to other firmware generations without a new compatibility check.

Historical reference: MIPS32, big-endian, Linux 3.10.107, uClibc, Freetz-NG commit `6e6c5d9c7d98ed150fe5ace0a1effc5b0e7a2f49` and runtime prefix `/usb/fritzwulf`.

Primary reference image: `7490_07.62.all_freetz-ng-29656-6e6c5d9c7d-ng26020_20260824-175155.image`, 45,178,880 bytes, SHA-256 `07d0df777957051d6cd1c8a88d8a01cc7c556a7e70ec2e271d753f3ac1f43727`.

The AVM DLNA metadata encoding fix is maintained under `tools/7490/dlna/`. Use the plan-only stager first; `--apply` is intended for a controlled Freetz source tree, not the historical reference tree. See `docs/dlna-encoding.md`.

Firmware flashing is a separate operation. Never infer the physical target from an IP address; verify the device, firmware version, backup and AVM recovery path before any flash action.
