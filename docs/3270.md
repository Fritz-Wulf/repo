# FRITZ!Box WLAN 3270

Status: **INFERRED**. The public profile covers the 3270 v2/v3 family only; it is not a blanket firmware-flash approval.

Freetz/Freetz-NG records identify the family as UR8/MIPS32. Firmware probes indicate little-endian operation. Historical 05.x generations span multiple kernels; the 05.50 v3 reference uses Linux 2.6.32.41 and uClibc 0.9.32.

Fritz.Wulf therefore uses the provisional package architecture `mips32-ur8-le`. Before any device-specific operation, detect the exact v2/v3 variant, firmware, kernel and runtime ABI. The historical Fritz.Wulf 3270 repository remains the next source for promoting this profile from inferred to historically verified.
